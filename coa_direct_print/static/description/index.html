Frequently Asked Questions

Do sales representatives need full Accounting access to print invoices?

No. The controller uses a secure elevation pattern that validates access on the source Sale Order or Customer, allowing sales reps to print invoices without granting them accounting rights.

Does it work on all web browsers?

Yes. The hidden iframe print technique is fully supported on modern Chromium browsers (Chrome, Edge, Brave) as well as Firefox and Safari. A manual preview fallback is also provided.

Can I print combined invoices for an entire order?

Yes. If an order has multiple posted invoices, the 'Print Invoice' button automatically bundles and prints them together.
